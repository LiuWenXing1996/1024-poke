# 胡 1024

> 用你写了十年的运算优先级，凑一个 1024。

一整副扑克牌（108 张：数字牌 + 王 + 运算符牌），从手牌往牌桌上放，按**四则运算优先级**拼出恰好等于 1024 的算式——

```
牌桌：13 × 13 × 6 + 10  =  1024  →  胡！
```

胡牌后桌上的牌洗回牌库，胡数 +1，继续下一手。**分数 = 胡牌次数**，看你在牌库耗尽前能胡多少。

## 玩法

1. 点「新游戏」，发 6 张手牌
2. 点手牌放到牌桌，保持数字、运算符交替（放 ÷ 时自动校验整除，除不尽直接拦下）
3. 桌上总值凑到 **1024**，点「胡」！
4. 凑不上？Z 键逐张撤销、弃牌换血，或者重开再来

会玩 24 点就会玩这个——但这里按优先级求值（× ÷ 先于 + −），解锁「乘积项之和」结构，比如 `11 × 11 × 8 + 7 × 8`，解空间大得多。

## 功能

- ♻️ 资源循环：胡牌后桌牌洗回牌库，一局可持续打，分数上不封顶
- ↩️ 三条退路：回合内逐张撤销（Z）；僵局一键弃牌换血（弃牌移出本局）；随时重开
- 💾 存档系统：每局自动存档（保留最近 50 局），随时打开恢复，也可同种子重开
- 🎲 种子复盘：同种子 = 同牌序，把种子发给朋友，两人玩同一副牌比谁胡得多
- ⌨️ 快捷键：Z 撤销，全程键盘可玩

## 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm run test       # Vitest 单测
npm run typecheck  # vue-tsc 类型检查
npm run build      # 类型检查 + 产物构建
```

技术栈：Vite + Vue 3 + TypeScript，纯前端单页应用，零后端零登录。

- `src/engine/` — 牌堆 / 求值器 / 带种子随机流
- `src/game/` — 状态与动作（存档、撤销、随机流快照）
- `src/App.vue` — 界面与交互
- `tests/` — 引擎与存档往返测试
